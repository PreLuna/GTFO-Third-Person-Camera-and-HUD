# ThirdPersonHUD 说明

## 身份

- GUID：`PreLuna.ThirdPersonHUD`；版本：0.13.1；源码 managed。
- 主文档：[README](../README.md)。

## 功能

DivisionV3、FourCorner、Radial、Compact 四种本机第三人称 HUD；Insert 总开关、End 队伍信息、Pause 恢复原版。

## ModControl

- 页面：`第三人称HUD`，5 个即时可写控件：角色旁面板、个人读数、队伍摘要、场景提示、提示区。
- 本机视觉设置；通过 HUD JSON 桥/安全行级 CFG，不写玩法状态。
- 未开放：样式、布局尺寸、大量面板/提示细节（源码约 107 个 Bind）。

## 依赖与兼容

- 硬依赖 `PreLuna.ThirdPerson`。
- 与 ModControl 为软依赖；MicroMaster/第三人称镜头可共用但互不强制。

## 验证/安装

- 已安装 0.13.1；此前页面/开关/重开已由用户确认。
- 回退：`维护记录/游戏安装-20261108-C5/PreLuna.ThirdPersonHUD.0.13.0.before.dll`。

## 边界

只开放 5 个本地视觉开关；不承诺所有样式/布局字段可写。
