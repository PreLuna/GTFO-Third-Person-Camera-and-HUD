# ThirdPerson 说明

## 身份

- GUID：`PreLuna.ThirdPerson`；版本：0.6.3；源码 managed。
- 主文档：[README](../README.md)；机器登记：[repo.json](../repo.json)。

## 功能

第三人称镜头跟随、肩射、碰撞/空间避让、身体显示与身体比例修复；F6 开关。

## ModControl

- 页面：`第三人称镜头`，5 个即时可写控件：镜头距离、右肩偏移、支点高度偏移、肩射距离、左肩。
- 目标侧 `ThirdPersonControlApi` + JSON 桥 + 安全行级 CFG；F9/F10 热键内部保存会被状态吸收，外部修改返回冲突。
- 本机镜头，仅装 MOD 玩家生效；不控制 bot/任务。

## 依赖与兼容

- 无插件硬前置；与 `ThirdPerson.Contracts`、`ThirdPersonHUD` 同仓。
- ModControl 为软依赖；Contracts/HUD 版本保持现装。

## 验证/安装

- 已安装 0.6.3；用户已确认镜头/页面正常。
- 回退：`维护记录/第三人称可写-20261109/PreLuna.ThirdPerson.0.6.2.before.dll`。

## 边界

只开放 5 个字段；FOV、按键、碰撞掩码、预设等未开放；不保证全量相机参数可热改。
