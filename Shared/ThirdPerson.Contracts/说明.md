# ThirdPerson.Contracts 说明

## 身份

- 类型：共享接口/数据契约，不是独立插件；无独立版本。
- 主文档：[README](../../README.md)；源码：`Shared/ThirdPerson.Contracts/src`。

## 用途

为 ThirdPerson、ThirdPersonHUD、MicroMaster 等提供共享数据、接口和 HUD 有效性规则；不绘制、不写配置、不安装为 MOD。

## ModControl

- 无页面、无配置入口；不参与面板写入。
- 现装 Contracts 与 ThirdPerson/HUD 组合已通过加载测试。

## 依赖与兼容

- 由 ThirdPerson/HUD 程序集引用；不是 BepInEx 插件。
- 变更时必须同时回归 ThirdPerson、HUD 与 MicroMaster 的摄像头/接管协议。

## 边界

不把 Contracts 当独立 MOD 或 Release 发布；不提供运行时配置。
